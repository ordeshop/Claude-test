# KOMLA — Photographer portfolio (demo)

Deploy-ready static site: `index.html` + `images/`. Fictional demo built as a client test.

## Run locally (localhost)
```bash
cd komla
python3 -m http.server 8000
# then open http://localhost:8000
```
(No Python on Windows? Just double-click index.html.)

## Deploy (live URL)
Drag this folder onto https://app.netlify.com/drop → instant live URL. Connect a domain, done.

Images are AI-generated stand-ins; for a real photographer these would be their own photos.
